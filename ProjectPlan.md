Overview:
Build a typing program that will teach a kid to type in 15 minute daily increments.

The program should meet all of these requirements:
1) It should run in windows, in a browser window.  It should run locally and be able to be opened with a single icon on the desktop.
2) It should track progress and pick back up where the child left off
3) It should have teaching, practice, games, and evaluation sections
4) It should adapt to reinforce lacking skills dynamically
5) It should be visually apealing and fun for a 9 year old
6) It should scale up to 30 WPM across the full keyboard
7) It should have an analysis page to show detailed performance

The code should be built with the following in mind:
1) It should be very modular in design.  Each activity/game/evaluation should be modular allowing them to be independently changed
2) It should have a robust testing environment where each module has unit tests and a modual test.  Integration and end to end tests
      should exist to show how these all work together.  Tests should be run as we modify each section.
3) It should be performant and minimal as much as possible.  Passes should be taken to reduce code duplication and keep things
      easy to read and understand.
4) It should follow best practices of coding in the approprate language.
5) Code should all be in github.  We'll version reguarly as per best practices and commit code to github as we make and test changes.
     All committed code should be run through the test suite successfully before we commit it.

The program should be built with best practices in learning typing
1) Search out papers on best ways to learn typing and ensure the program follows them
